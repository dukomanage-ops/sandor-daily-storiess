# Sandor Hernandez — Daily Stories

Public host for the daily Miami Market Brief Instagram Stories (@sandor_realtor) and the full PDF report.

- `stories/YYYY-MM-DD/story-NN.jpg`: 1080×1920 story slides
- `stories/YYYY-MM-DD/miami-market-brief-YYYY-MM-DD.pdf`: full report (sent to people who reply REPORT)
- `build_story.py spec.json outdir`: renders slides from a day's spec
- `build_report.py out.pdf`: renders the report
